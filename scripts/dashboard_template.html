Does working longer help?

One dot per model per field: how many steps a typical run takes (median) against the share of criteria it passes. Up and left is better: more right answers for less work.

Steps are a proxy, not a price. The traces contain no token, cost, or latency data, so the x-axis counts trajectory steps (tool calls and messages). Step formats differ slightly across models; compare shapes, not decimals.
